# Code to reproduce the results of "Multi-omics network reconstruction with collaborative graphical lasso"
This repository contains the code to reproduce the results from the manuscript 
"Multi-omics network reconstruction with collaborative graphical lasso". This 
includes the simulations and the application of collaborative graphical lasso 
to a multi-omics study of sleep deprivation.

BEFORE RUNNING:
- Every file contains elements in the first few code lines that need to be
adjusted by the user, and the end of the part to be customized is clearly
specified;
- The files "sim1..." to "sim3..." need to be run sequentially;
- The file "sim1_generate_data.R" has the code to install the required packages
to reproduce all of the simulations.
